# Направление в никуда / Direction to Nowhere 🌌

Интерактивная книжная серия-дилогия (двухтомник-перевертыш), созданная на стыке **неевклидовой геометрии, релятивистской физики и системного программирования на языке Rust**. 

Проект разработан ИТ-архитектором и призван сломать парадигму «упрощенного» детского программирования, заменив её строгой математической логикой, наглядным визуальным рендерингом и архитектурным мышлением.

---

## 💡 О концепции серии

Дилогия разделена на два тома, которые представляют собой классическое инженерное разделение на **слой представления (Presentation)** и **движок вычислений (Engine)**:

*   **Том 1: «Путешествие Навигатора» (Сюжетная сказка)**  
    Художественная научно-фантастическая история для детей 10–14 лет. Герои исследуют аномальные неевклидовы пространства, сталкиваются с релятивистским замедлением времени из-за вращения на скорости света и ищут выход из «сетевой черной дыры» (Deadlock). Через сюжет ребенок развивает пространственную и алгоритмическую интуицию.
*   **Том 2: «Алгоритмы визуализации» (Техническое руководство)**  
    Книга для продвинутых подростков и родителей. Она полностью открывает «капот» первого тома и пошагово учит писать на Rust графический движок трассировки лучей (Ray Tracing) и физический симулятор, которые сгенерировали иллюстрации к первой книге.

### Уникальные торговые предложения (УТП) для издательств:
1. **Математическая честность:** Иллюстрации в книгах не нарисованы от руки абстрактно. Это точные векторные рендеры и графики численного интегрирования физических полей. Каждая картинка первого тома — результат работы кода из второго тома.
2. **Интерактивный «Эффект Триумфа»:** Дописывая алгоритмы в конце глав второго тома и запуская код на своем компьютере, ребенок генерирует PNG-файл, который пиксель-в-пиксель совпадает с глянцевой иллюстрацией в печатной книге.
3. **Rust как стандарт:** Вместо «игрушечных» сред (вроде Scratch) ребенок сразу осваивает взрослые концепции: структуры данных, строгую типизацию, перечисления (`enum`), трейты (`trait`) и асинхронность (`async/await`).

## 📁 Структура репозитория пилота

Проект организован в соответствии со строгими правилами Cargo-пакетов и содержит полноценный MVP ключевой пятой главы (Торус + Черная дыра):

```text

├── 02_Synopsis_and_Chapter_Plan.md  # Подробный синопсис и план дилогии
├── 03_Demo_Chapter_Torus/
│   ├── Volume1_Chapter_Draft.md    # Художественный текст демо-главы (Том 1)
│   ├── Volume2_Chapter_Code_Guide.md # Руководство по коду для детей (Том 2)
│   └── src/
│       └── main.rs                 # [РАБОЧИЙ КОД] Физический симулятор луча
└── 04_Visual_Assets/
    ├── Layout_Concept.md           # Концепция верстки страниц (код + текст)
    └── torus_blackhole_render.png  # Сгенерированный алгоритмом рендер траектории
```

## 🚀 Быстрый запуск демо-симулятора

В репозитории находится полностью рабочий код симулятора гравитационного искривления пространства. Чтобы запустить его локально, выполните следующие шаги:

1. Убедитесь, что у вас установлен компилятор Rust (издание 2021 или новее).
2. Склонируйте репозиторий и перейдите в его корень.
3. Запустите расчет симуляции через Cargo:

```bash
cargo run --bin chapter_5_blackhole
```

### Лог успешного выполнения («Триумф»):
При стандартных настройках масса черной дыры `G_MASS = 150.0` искривит траекторию, и программа зафиксирует безопасный перехват луча без зависания системы:
```text
[LOG] Запуск бортовой навигационной системы станции Торус-12...
[LOG] Расчет траектории луча при массе черной дыры G_MASS = 150...
[LOG] Предупреждение: Луч захвачен гравитационным капканом!
[LOG] Статус вычислений: Триумф!
```
